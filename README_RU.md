# 🔐 Генератор паролей



Простой консольный генератор паролей на Python. Создаёт случайный пароль нужной длины с помощью криптографически стойкого модуля `secrets`.

## Возможности

- Длина пароля от **8 до 20** символов
- Используется `secrets` (а не `random`) — модуль, предназначенный для задач, связанных с безопасностью
- Без внешних зависимостей
- Понятное сообщение, если длина вне допустимого диапазона

## Требования

- Python 3.13.7 (версия, на которой написан проект)
- Должен работать и на любой версии Python 3.6+, так как модуль `secrets` появился в 3.6

## Использование

1. Склонируйте репозиторий или скачайте скрипт.
2. Запустите его:

   ```bash
   python secpass.py
   ```

3. Введите нужную длину пароля, когда программа об этом попросит.

### Пример

```
How long should the password be? 8-20 digits12
k3#x9qmw2ptz
```

Если длина выходит за допустимые границы:

```
How long should the password be? 8-20 digits5
password is too short or too long
```

## Как это работает

1. Программа запрашивает длину пароля.
2. Проверяет, что число находится в диапазоне от 8 до 20.
3. Для каждой позиции выбирает один случайный символ из допустимого набора через `secrets.choice()`.
4. Символы объединяются в строку и выводятся на экран.

## Набор символов

В пароле могут встречаться:

- строчные латинские буквы `a–z`
- цифры `0–9`
- символ `#`
